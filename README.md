# ForgeYarn

Decentralized, multi-threaded application platform utilizing auto-scaling, resource-optimized architecture for scalable, concurrent deployment management.

With ForgeYarn, you get a lightweight tool that stays out of your way.

**What you get**

- Decentralized, multi-threaded application platform utilizing
- auto-scaling, resource-optimized architecture for scalable,
- concurrent deployment management

- python

- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/ForgeYarn.git`
2. `cd ForgeYarn`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
